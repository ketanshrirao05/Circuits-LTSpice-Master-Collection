## 🛠️ How to Use

### 1. LTSpice Simulations
1. Download and install [LTSpice](https://www.analog.com/en/design-center/design-tools-and-calculators/ltspice-simulator.html).
2. Click any `.asc` file link above to navigate to it, then download or clone the repository locally.
3. Open the schematic in LTSpice and click **Run** (🏃) to begin time-domain (`.tran`), frequency-domain (`.ac`), or DC sweep (`.dc`) analysis.

### 2. Python Calculation Scripts
Certain folders (e.g., `Filters`, `Comparator circuits`) contain Python helper scripts to evaluate mathematical models and frequency parameters.
* **Dependencies:** `python3`, `numpy`, `matplotlib`, `scipy`
* Run via terminal:
  ```bash
  python3 Filters/RC/RC.py
